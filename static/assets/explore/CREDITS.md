# Explore demo images

This folder contains a deliberately small, local Pexels image set for the NSosyal prototype. Keeping the files local makes the competition demo work without an API key or a network request.

The image is visual context only. The post caption is the input to the sentiment model; no emotion, wellbeing, or ranking conclusion is inferred from an image.
